# SIEM Log Detection Tool

This project demonstrates a simple security detection script designed to simulate how a SIEM platform identifies suspicious activity within log data.

## Overview

The script parses log files and detects potential security threats based on predefined patterns such as:
- Failed login attempts
- Unauthorized access
- Invalid user activity
- SQL injection indicators

## Purpose

This project reflects real-world security operations workflows including:
- Log analysis
- Detection engineering
- Alert generation
- Threat identification

## Technologies Used
- Python
- Regex pattern matching

## How to Run

1. Place your log file in the same directory
2. Update the filename in the script if needed
3. Run:

```bash
python log_detector.py
